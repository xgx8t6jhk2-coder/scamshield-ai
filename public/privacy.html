Privacy by design

A scam checker sees people’s most private messages — bank alerts, family chats, blackmail. ScamShield is built so that it does not need to keep any of it.

1. Three privacy tiers — the user chooses

ModeWhat leaves the deviceWhat is stored
On-device (toggle off)Nothing. The engine is a 30 KB JavaScript file that runs in the browser, the PWA and the extension.Nothing.
Deep check (default)The text or link, over HTTPS, to the Cloudflare edge for live checks (redirects, domain age, page inspection) and the AI analyst.Nothing about the content. Only an anonymous daily counter: date, input kind, verdict.
Report (opt-in click)A structural fingerprint only (below).The fingerprint, plus optional emirate and “lost money” tick.

3. Screenshots and QR codes

Text recognition (Tesseract, Arabic + English) and QR decoding (jsQR) run inside the browser. The image is never uploaded. Only the extracted text follows the user’s chosen mode.

4. The AI analyst

The language model runs on Cloudflare Workers AI (open-weight Llama models), not a third-party chatbot vendor. Prompts are not used to train models and are not logged by ScamShield. The model is a second opinion: it can raise a borderline verdict or soften a weak one, but never overrides strong rule evidence, so every decision remains explainable.

5. Browser extension

Every page visit is checked locally. Browsing history is never sent anywhere. A report is sent only when the user clicks “Report”.

6. Police dashboard

Analysts see aggregates and domains — information about the criminal infrastructure, not about victims. Status changes require an analyst key. Synthetic demo data is flagged demo = 1 and can be hidden with one switch.

7. Alignment with UAE law

Designed around data-minimisation and purpose-limitation principles of the UAE Personal Data Protection Law (Federal Decree-Law No. 45 of 2021). No special-category data is processed; reports are anonymous by construction, so they cannot be linked back to a person. Production deployment would host data in-country and add a formal DPIA.

بالعربية باختصار

الفحص على الجهاز لا يرسل أي شيء. الفحص المعمّق يحلل النص ثم يتخلص منه فوراً. البلاغ اختياري ولا يحتوي على نص الرسالة أو رقم الهاتف أو عنوان IP — فقط الجهة المنتحلة ونوع الاحتيال والنطاق. لقطات الشاشة ورموز QR تُقرأ داخل هاتفك ولا تُرفع أبداً.
